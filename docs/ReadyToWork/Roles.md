# Roles

Manticore Streams separated for two type of roles: [Admin](ReadyToWork/AdminSection.md) and [Manager](ReadyToWork/ManagerSection.md)

# Admin Section

* The administrator can create and delete managers.
* Indicate where to [get](ReadyToWork/Admin/Source.md) the messages and where to [put](ReadyToWork/Admin/Destination.md) the results.
* Create stream templates ([processing](ReadyToWork/Admin/Process.md)).
* Create streams by adding users to processing, as well as stop and delete streams

# Manager Section

* Can add/remove rules for Stream
* May has many Streams onetime
* Can view results and graphics
